## 🔗 Final Year Project

### Comparing Curricular Learning against a Traditional Reinforcement Learning Algorithm

My final year project compared training a **virtual robot to walk** using:
- A **predefined (traditional) reinforcement learning algorithm**

This project was incredibly rewarding — it deepened my understanding of ML training strategies and gave me hands-on skills in reinforcement learning that I continue to apply today.
